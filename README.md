# Drona

Drona is my self-made productivity optimization app built using SwiftUI for macOS.

It helps streamline my workflow, improve focus, and make my daily life more productive and systematic.

## Features
- Productivity tracking
- GitHub integration
- LeetCode tracking
- Widgets support
- Clean macOS-native UI

## Tech Stack
- SwiftUI
- WidgetKit
- GitHub API
- macOS Development
